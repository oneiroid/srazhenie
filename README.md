# Сражение

Браузерная версия советской настольной игры «Сражение» (вариант «Стратего»): поле 10×10 с двумя озёрами,
по 40 фишек у каждой стороны, звания скрыты от противника до боя. На фишках вместо цифр — портреты.
Два набора портретов переключаются в меню: «Классика» (армия 1812 года) и «Номенклатура» — советские вожди
и палачи: Сталин, Берия, Ежов, Ягода, Вышинский и другие.

**Играть:** https://oneiroid.github.io/srazhenie/

## Режимы

- **Против компьютера** — два уровня: «Новобранец» и «Ветеран». ИИ видит только то, что видел бы человек.
- **Вдвоём на одном устройстве** — между ходами экран закрывается, пока устройство передают.
- **По сети** — создайте партию и отправьте ссылку или код. Сервер не нужен: сообщения идут через публичные
  MQTT-брокеры (EMQX, HiveMQ, Mosquitto), клиент подключается ко всем сразу.

Работает на телефоне и компьютере; партии сохраняются в браузере и продолжаются после перезагрузки.

## Правила

| Звание | Кол-во | Особенность |
|---|---|---|
| Маршал | 1 | Сильнейший; погибает, если на него нападёт Разведчик |
| Генерал | 1 | |
| Полковник | 2 | |
| Майор | 3 | |
| Капитан | 4 | |
| Лейтенант | 4 | |
| Сержант | 4 | |
| Сапёр | 5 | Обезвреживает мины |
| Солдат | 8 | |
| Разведчик | 1 | Побеждает Маршала, только нападая первым |
| Мина | 6 | Не ходит; уничтожает нападающего, кроме Сапёра |
| Знамя | 1 | Не ходит; захват — победа |

- Все фишки ходят на одну клетку по вертикали или горизонтали; через озёра ходить нельзя.
- Атака — ход на клетку с фишкой противника. Младшая фишка снимается, при равных погибают обе;
  победивший нападающий занимает клетку.
- Белые ходят первыми. Победа — захват знамени или отсутствие ходов у противника.
- Дополнения к оригинальным правилам: одна фишка не может ходить туда-обратно между двумя клетками больше трёх
  раз подряд; 200 ходов подряд без сражений — ничья.

## Честность сетевой игры

Звания не передаются. При расстановке каждая сторона отправляет для каждой фишки
`sha256(комната|партия|фишка|звание|соль)`. В бою раскрываются звание и соль только двух участвующих фишек,
соперник сверяет их с отпечатком. В конце партии раскрываются все фишки, и проверяются отпечатки, состав армии
и то, что мины и знамя не двигались.

## Разработка

Чистый HTML/CSS/JS без сборки.

```
python3 tools/serve.py 8731   # локальный сервер без кэша
node tests/selfplay.js 40     # ИИ против ИИ
node tests/online.js 4        # сетевой протокол на двух клиентах в памяти
```

Портреты сгенерированы локально (SDXL, `tools/gen_art.py --set <набор>`) и превращены в маски
(`tools/process_art.py`, выбор кадров — `art/picks.json`);
цвет фишкам задаёт CSS.
